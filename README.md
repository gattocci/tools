# gattocci/tools

Indice de herramientas pequeñas para acelerar tareas repetitivas en VS Code y
Windows. Cada herramienta vive en su propio repositorio para conservar un
historial, una versión y una distribución independientes.

Estas son las herramientas que uso en mi día a día, son fáciles de instalar. Son para acelerar tareas repetitivas.

Cada herramienta vive en su propio repositorio para conservar un historial, una versión y una distribución independiente. Si las actualizo en algún momento se actualizarán en su repositorio independiente.

## Publicadas

| Herramienta | Que hace |
| --- | --- |
| [File to TXT](https://github.com/gattocci/file-to-txt) | Copia archivos a `.txt` con una marca de tiempo. Estado excelente. |
| [Tree to Folder](https://github.com/gattocci/tree-to-folder) | Crea archivos y carpetas desde un arbol de texto. Bugs menores. |
